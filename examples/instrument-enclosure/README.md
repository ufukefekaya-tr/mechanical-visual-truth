# Open instrumentation enclosure

An open enclosure with a panelled front, display and control proxies, four board standoffs, and a simple internal module. The display aperture is formed from separate shell panels; all geometry comes directly from boxes and cylinders in this contract. Bend allowances and electrical certification are outside its scope.

All units are millimetres. These simple solid envelopes illustrate concept verification; bores, threads, tolerances, forces, and vendor specifications are not represented. They are not manufacturing drawings.

```bash
mvt contract validate examples/instrument-enclosure
mvt build examples/instrument-enclosure
mvt render examples/instrument-enclosure --set proofs
mvt audit examples/instrument-enclosure
```

Source: original synthetic public example, created without importing prior customer or personal geometry and dimensions.
