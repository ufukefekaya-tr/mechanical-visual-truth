# Changelog

## 0.2.0 — 2026-10-18

First project-independent public release by Ufuk Efe Kaya, under MIT OR Apache-2.0.
The release starts from a clean public history without private project state.

- Official stdio MCP server with thirteen workspace-scoped tools, native image
  previews, serialized isolated workers and bounded resource use.
- Standalone package resources, explicit project paths and three synthetic
  templates. CLI and MCP share the same operations.
- Hash-locked contract-local STEP/BREP imports, explicit assembly actor identity,
  local cuts, hex prisms and rigid transforms.
- Independent STEP reload and true geometry comparison, exact native bounds,
  stable solid signatures, arbitrary CAD plane sections and vector drawings.
- B-rep clearance/collision checks, explicit motion coverage, grouped actors,
  rotation pivots, authored-pose sampling and corrected GIF playback timing.
- Sharper proof rendering with bounded mesh reuse and visible trust labels.
- Separate geometry/concept and physical/safety results; deferred checks are
  recorded rather than promoted into a safety or manufacturing claim.
- Three public STEP examples, nine rendered proof views, three native technical
  drawings and a deterministic motion demonstration, with reproducible hashes.
- Regression coverage for source tampering, changed internal geometry,
  triangulation effects, output traversal, symlinks, stale edits, moved runs,
  protocol lifecycle and the installed package boundary.

See docs/UPSTREAMING.md for the reviewed later revisions and deliberate exclusions.
