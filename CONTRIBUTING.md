# Contributing

Use Python 3.12, install `.[dev]`, and run `pytest` before proposing a change.
Add a small synthetic regression for a real geometry, source-lock, rendering or
protocol bug. Do not submit customer models, conversations, credentials or
absolute workstation paths. New examples must state their provenance and
license and be reproducible from an included public contract or source.

Contributions to original code and examples are submitted under MIT OR
Apache-2.0, the same dual-license terms as this project. Preserve third-party
notices and separate physical/safety limits from a geometric result.
